# MacEase

MacEase 是面向 macOS 15 及以上、Apple Silicon 的网易云音乐第三方原生音乐客户端，
使用 Swift 与 Apple 原生框架直连网易服务，采用 MIT 许可证。

产品目标是一个精简、高效、完备、原生的音乐软件：用户可以发现音乐、管理个人音乐库、
在线收听与离线播放，开发者完成基础功能后可以专注于 UI 设计和歌词表现。
**当前为 pre-alpha，主要基础能力已有实现，但仍有功能缺口与真实环境验收，尚未达到这一目标。**

## 完备的定义

完备指下列基础音乐任务均有可用的原生入口、完整业务实现、正确的失败处理与验证证据。
这些是产品完成要求，不是当前已全部实现的声明。

| 能力 | 完成要求 |
|---|---|
| 登录与账号 | 二维码、短信和官方网页登录；账号资料展示、Keychain 会话、自动恢复与续期、退出及账号隔离。 |
| 发现与搜索 | 每日推荐及推荐历史、歌单推荐、榜单、新歌/新碟、分类/精品歌单、雷达、相似音乐、私人 FM/心动模式；歌曲/专辑/歌手/歌单搜索、建议、热搜、搜索历史和完整分页。 |
| 音乐资料 | 歌曲、专辑、歌手、歌单之间可导航；完整曲目集合、必要简介/封面/曲序、收藏状态、权限和不可播原因。 |
| 个人音乐库 | 我喜欢的音乐、创建/收藏歌单、专辑收藏、歌手关注；歌单创建/删除、名称/描述/标签/封面编辑、排序、批量增删曲目和写后同步。 |
| 云盘 | 文件上传、列表/详情/容量、导入、匹配调整、播放、下载和删除。 |
| 播放与队列 | 音质选择与实际音质显示、播放/暂停/seek/音量、连续/随机/循环、完整集合播放、队列追加/插入/重排/删除、恢复和定时停止。 |
| 下载与离线 | 单曲/批量下载、进度/取消/重试、试听与完整文件区分、空间管理；断网冷启动、离线播放/seek、队列恢复和已保存歌词。 |
| 歌词 | LRC/YRC、翻译/罗马音、可靠的行/词时间数据、同步显示、点击跳转、偏移调整和离线读取；表现层共享一个播放时钟。 |
| 记录与日常操作 | 真实播放反馈、按时间的最近歌曲/专辑/歌单、听歌排行、本地历史、Dock 最近来源、歌单内过滤、分享链接复制与打开。 |
| macOS 整合 | Now Playing、媒体键/系统遥控、音频路由、睡眠/唤醒、网络变化、Dock/菜单/快捷键、原生通知、设置与可安装制品。 |

功能以网易服务端能力、账号权限和原生解码能力为准；不绕过试听、付费或版权限制。
协议暂缺证据时记录具体限制并继续核实，不能将其标记为已完成或无期限降为可选。

## 当前实现

已有 QR/SMS/网页登录、会话自动恢复与续期、离线身份、主要发现与四类搜索、收藏导航、
完整歌单/歌手集合播放、歌单字段/封面/排序与批量维护、云盘上传/导入/匹配、正式下载和
串行批量任务、队列编辑/恢复、最近播放与本机历史、歌词同步/偏移/离线保存，以及系统媒体、
Dock 来源、通知和 Sparkle 更新接入。接口与协议状态均留在现有原生模块中。

这些能力已有最小原生入口和离线验证，真实账号的完整任务、会员权限、NOS/CDN、反馈统计、
音频设备及签名制品仍待验收；部分请求只有限定样本的真实兼容证据。公开歌单转隐私仍缺
权威协议依据。不能将代码和离线测试通过等同于产品已全部真实可用。

## 产品边界

- 只服务网易云音乐，不移植 API-Enhanced 的全部模块，不以端点数量衡量完成度。
- 不实现评论/私信/动态等社交业务、视频/MV、播客/DJ/广播、一起听、会员购买、云贝任务、
  创作者工具或通用 API 代理。歌手关注和会员播放权限展示属于基础音乐能力，仍需实现。
- 不实现第三方音源灰歌解锁，不接入 Kuwo、Kugou 等来源，也不建立多音源抽象。
- 云盘上传的本地文件属于网易音乐库流程；不扩展为通用本地媒体管理器。
- 桌面/沉浸歌词、复杂逐字动画、频谱与外观设计属于后续表现阶段；基础歌词数据、
  时间同步与离线能力必须先完成。双语本地化与审校安排在基础功能之后。

## 构建与运行

需要 Apple Silicon Mac、macOS 15 及以上和可编译 Swift 6 的 Xcode 工具链。
项目使用系统框架；SwiftPM 依赖 Sparkle，精确版本由 Package.swift 和 Package.resolved 固定。

在仓库根目录运行：

```sh
swift test --package-path Packages/MacEaseCore
./scripts/package_macease_app.sh --check
./scripts/package_macease_app.sh
open .build/MacEase.app
```

组装脚本默认构建 arm64 Release 并使用 ad-hoc 签名，产物用于本地验证；已存在同名产物时
默认拒绝覆盖，其他参数见 `./scripts/package_macease_app.sh --help`。
本地制品不等于已完成 Developer ID 签名、公证或公开发布。

公开分发目标为 GitHub Releases 与 Homebrew。正式签名、公证、更新源配置和实际发布尚未
完成；Sparkle 未配置有效更新源和公钥时保持禁用。
