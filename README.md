# MacEase

MacEase 是使用 Apple 原生技术开发的 macOS 网易云音乐第三方客户端，采用 MIT
许可证。本文定义公开产品范围；实现状态与后续计划分别记录在本地开发文件
`docs/status.md` 和 `docs/plan.md` 中。

> 本项目除 README.md 外的 Markdown 都是本地工作文件，不纳入 Git 或 GitHub。

## 长期规则

- 使用 Swift、SwiftUI 和 Apple 原生框架，不使用任何跨平台框架，例如 Electron。
- 只服务网易云音乐，不建立多音源抽象；网络协议统一由 `NeteaseKit` 承担。
- 目标平台为 macOS 15 和 Apple Silicon，界面遵循 macOS 原生设计。
- 公开版本的分发目标为 GitHub Releases 和 Homebrew；实际 D1 发布尚未完成。
- Sparkle 及其附带第三方组件的许可原文见
  [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt)。

## 目标用户与核心任务

面向希望在 macOS 上使用网易云音乐核心能力、同时保留系统原生体验的用户。当前工程
完成目标是让登录、音乐库、发现、综合与分类搜索、详情、播放、歌词、下载、反馈和系统
整合等网易云音乐原生功能基本完备；真实账号、设备和公开发布仍需人工验收。

- 登录与账号：WKWebView 官方登录页、原生二维码、短信验证码、服务端退出、手动刷新、
  已验证账号每日一次自动会话刷新和 Keychain 会话恢复。
- 音乐库：用户歌单、红心、听歌记录与排行、专辑收藏、歌手关注、云盘及全部用户明确
  发起的创建、编辑、收藏、删除操作。
- 发现：每日推荐、推荐歌单、榜单、分类与精品歌单、雷达、新歌、相似歌曲与歌手、
  私人 FM、FM trash 和心动模式。
- 搜索与详情：歌曲、专辑、歌手、歌单分类搜索及分页、四类并发综合搜索、搜索建议；
  专辑、歌手、歌单完整详情。
- 播放：五档音质、队列与播放模式、seek、定时停止、播放恢复、临时缓存、下载与
  离线播放。
- 歌词：LRC、YRC、翻译、罗马音和应用内逐行显示。
- 账号反馈：听歌上报（scrobble）、听歌记录和排行。
- 系统整合：Now Playing、媒体键、蓝牙遥控、音频设备切换、sleep/wake、Dock 菜单、
  快捷键、队列恢复和原生通知。

## 产品边界与后续阶段

- 明确排除跨来源灰色歌曲解锁；MacEase 只服务网易云音乐，不建立 Kuwo、Kugou 等
  多音源实现。
- 沉浸式播放页、音频频谱、完整双语本地化、本地 Dock 最近播放历史，以及桌面歌词、
  逐字动态歌词表现，属于后续 UI、历史数据或细节打磨阶段，不是当前工程完成
  边界。
